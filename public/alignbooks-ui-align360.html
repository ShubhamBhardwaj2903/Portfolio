01 — Overview

Two launches.
One designer.

This project had two parallel tracks running simultaneously. The first was an internal product design challenge — redesigning the AlignBooks application UI to create a unified, consistent, and modern experience across all modules for existing users.

The second was an outward-facing launch moment — the introduction of Align360, a dedicated enterprise ERP tier positioned above AlignBooks, targeting medium-to-large businesses and MNCs. It needed its own brand identity, landing page, and a full go-to-market campaign.

As the sole designer, I owned both — from the micro-detail of reorganising button placements in transaction screens, to the macro-level of crafting a launch narrative and campaign assets delivered to thousands of users via Gmail and WhatsApp.

02 — UI Redesign

Rebuilding the product
screen by screen.

The AlignBooks UI had grown organically over years — each module added features independently, leading to a fragmented experience. Buttons were in different positions across screens. Toolbars were crowded. The item table in transaction screens was cluttered and required heavy horizontal scrolling.

The redesign wasn't a visual rebrand — it was a systematic decluttering. Every action was audited: is it frequent? Is it where users expect it? Does it compete with more important actions for visual weight?

The result was a unified interface language that applies consistently from Sales & Billing to HR & Payroll — same button hierarchy, same dropdown patterns, same grid behaviour, same icon set.

The goal was that a user who learned one module would feel immediately at home in any other — reducing training time and improving daily efficiency for the thousands of users who touch AlignBooks every day.

Before
The old interface
  • Open, Delete, Copy, Cancel, Restore, Calculator, Help, Configuration all crammed in a single top toolbar — no hierarchy
  • Item table options (Add Rows, Search, Barcode, Copy Row) scattered across the table width, requiring horizontal scroll
  • Serial, Dimensions, and Bundle taking up permanent item table columns — reducing visible item data
  • Logistics, Shipping, E-Way Bill and E-Invoice all mixed together in the bottom section without grouping
  • Print Configuration and Schedule buried at the bottom-left — hard to find, frequently needed
  • Reports listed as a flat, unsearchable long list — no organisation by type or frequency
  • Dashboard icons inconsistent in size and style across modules
  • Help icon generic — linked to a homepage, not the current screen's documentation
  • Module menu: a long flat list with no grouping or search
After
The redesigned interface
  • Top-right: Open, Delete, Copy, Help, Calculator. Secondary actions (Cancel, Recall, Restore, Schedule, Config) moved into a clean dropdown
  • All item table row actions grouped under a single ⋮ menu — freeing up visible item columns
  • Serial, Dimensions, Bundle moved to a dedicated ⋮ submenu — item table now fits more data per screen without scrolling
  • Bottom section reorganised into dedicated, expandable groups: Logistics, Shipping, E-Way/E-Invoice — each with relevant options only
  • Print Configuration moved to top-right dropdown; less-used actions consistently deprioritised across all screens
  • Reports completely redesigned: searchable, organised by chips (Primary, Category, Document, Industry, Role), with count badges and recently visited
  • Dashboard icons updated with consistent sizing, spacing, and a unified style guide
  • Help icon now links directly to the documentation for the current active screen
  • Module menu: searchable, grouped into expandable submenus — structured navigation replacing the long list

Key Changes at a Glance

Every change had a clear rationale — reduce clutter, improve discoverability, or create consistency.

Transaction Toolbar
Primary actions stay visible. Secondary and rare actions move into a clean dropdown — reducing cognitive load without hiding functionality.
Item Table Redesign
Collapsed Serial, Dimensions, Bundle into a ⋮ submenu. Grouped row-level actions into a single three-dot menu. More data visible, no horizontal scroll.
Bottom Section Grouping
Logistics, Shipping, and E-Way/E-Invoice now live in labelled, expandable sections — eliminating the visual noise of mixed fields at the bottom of every transaction.
Reports Redesign
Searchable, chip-filtered (Primary, Category, Document, Industry, Role). Report counts per section, recently visited, action buttons moved to top.
Module Menu Navigation
Long flat link lists replaced with a searchable, grouped sidebar — expandable submenus per module category. Navigation that scales with product depth.
Privacy Eye Icon
New dashboard control to instantly hide financial data during screen sharing or meetings — a small feature that addresses a very real daily concern for business users.
Contextual Help
The help icon in every module now links directly to documentation for the current screen — no searching. Also surfaces Tickets, Tutorials, FAQs, and Release Notes.
Enterprise Dashboard
Fully customisable dashboard widgets redesigned with a modern layout and better data visualisations — role-based insights for decision-makers at a glance.

04 — Go-to-Market Campaign

Building hype before
the curtain rose.

Launching a new enterprise product isn't just a design problem — it's a storytelling and sequencing challenge. Simply announcing Align360 on launch day would waste the opportunity to build anticipation within AlignBooks' existing user base of thousands.

I designed a staged, multi-touch campaign across Gmail and WhatsApp — starting weeks before launch — that took users on a deliberate journey from curiosity to excitement to conversion.

Each phase had a distinct visual language and a specific goal. Teasers were intentionally minimal and mysterious — enough to intrigue, not enough to explain. Sneak peeks revealed specific features one at a time. The date announcement created urgency. The launch itself was the payoff moment.

Post-launch, follow-up campaigns targeted users who had engaged with earlier touchpoints but hadn't yet explored the new product — keeping the conversation alive beyond day one.

05 — Impact & Scope

The scale of
what was built.

This was one of the most expansive solo design undertakings of this portfolio — touching both the internal product experience (thousands of daily users) and the outward brand narrative (a new enterprise product launch reaching the full AlignBooks customer base).

The UI redesign touched every module in the product — Sales, Finance, Inventory, POS, HR & Payroll, Production, Job Work, Asset Management — ensuring consistency not just on one screen, but across the entire application surface area.

  • Every transaction screen across all 9 modules received the standardised toolbar and item table redesign
  • Reports, Dashboards, and Module Menu redesigned — the three highest-frequency areas of the product
  • Align360 brand identity designed from scratch — separate from AlignBooks but within the same design family
  • A full 5-phase campaign executed across two high-reach channels: Gmail and WhatsApp
  • Each campaign touchpoint individually designed — not repurposed templates but purpose-built assets per phase and channel

06 — Reflections

What this project
taught me.

01
UX Is About Frequency, Not Just Usability
The biggest insight from the UI redesign was distinguishing between features by how often they're used. Moving rare actions into dropdowns and promoting frequent ones to persistent toolbars made the interface faster for daily users — not by adding anything, but by getting out of the way.
02
A Launch Is a Narrative, Not an Event
Designing the Align360 campaign taught me that a product launch is most effective when it's treated as a story with chapters — not a single announcement. The teaser-to-launch arc turned passive existing users into an engaged audience who felt like they were part of something unfolding.
03
Channel Context Shapes the Design
Gmail and WhatsApp have completely different consumption contexts — email is opened with intent and held for longer; WhatsApp is scanned in seconds on mobile. The same campaign message required a fundamentally different visual approach per channel, not just a resize.
04
Consistency Is a Product Feature
After the UI redesign, the most common feedback from users was that the product felt "cleaner" — not that any specific feature was better. Consistency itself is experienced as quality. When everything behaves predictably and looks like it belongs together, users feel more confident and capable.
